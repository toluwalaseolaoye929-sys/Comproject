## 📖 About the Project

Suzan Unisex Salon is a full-stack web development project created to give a beauty business a professional online presence.

The platform is designed to help customers explore salon services, discover trending hairstyles, meet the salon team, and make booking enquiries.

The project focuses on combining modern design, accessibility, responsiveness, and practical business functionality.

## ✨ Features

- **Modern Homepage:** Elegant and visually appealing landing page.
- **Services Showcase:** Display of salon services and beauty treatments.
- **Before & After Gallery:** Visual presentation of salon transformations.
- **Trending Hairstyles:** Showcase of popular hairstyles and beauty trends.
- **Meet Our Stylists:** Dedicated stylist profiles with individual photographs, specializations, and experience.
- **Appointment Booking:** Booking interface for customers.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Interactive UI:** Smooth interactions and intuitive navigation.

## 🚀 Installation & Setup

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate into the Project

```bash
cd Suzan-Unisex-Salon
```

### 3. Install Frontend Dependencies

```bash
cd client
npm install
```

### 4. Install Backend Dependencies

Open another terminal:

```bash
cd server
npm install
```

### 5. Configure Environment Variables

Create a `.env` file in the backend directory.

```env
PORT=5000
MONGO_URI=your_database_connection
CLIENT_URL=http://localhost:5173
```

Add other environment variables required by your application.

### 6. Start the Backend

```bash
npm start
```

### 7. Start the Frontend

```bash
npm run dev
```

Visit the local development URL provided by Vite.
